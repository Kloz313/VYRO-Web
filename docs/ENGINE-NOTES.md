# محرك التنزيل في نسخة الويب

- يستخدم الخادم إصدار yt-dlp المستقر 2026.10.26 أو أحدث عند إعادة بناء الصورة.
- تتضمن المتطلبات مكونات JavaScript اللازمة لاستخراج يوتيوب، مع تفعيل Node.js داخل yt-dlp.
- يتضمن الخادم مزود رموز إثبات المصدر الخاص بيوتيوب ويشغّله محلياً على عنوان loopback فقط؛ لا يحتاج الزائر إلى تسجيل الدخول أو رفع ملفات تعريف ارتباط.
- يرسل مستخرج يوتيوب طلبات عبر العملاء mweb وtv وweb_safari للاستفادة من مسارات التشغيل المتاحة.
- لموقع تيك توك، يستخدم yt-dlp طبقة curl_cffi مع محاكاة متصفح Chrome لتقليل أخطاء بصمة TLS.
- هذه التحسينات لا تضمن تجاوز حظر عنوان IP الخاص بمركز البيانات. توثيق yt-dlp ومزود الرموز يوضح أن رمز إثبات المصدر لا يحل وحده قيود تسجيل الدخول المرتبطة بعنوان IP؛ عند فرض المنصة ذلك، قد يستمر الفشل دون جلسة مستخدم.
- يجب اختبار الروابط الحقيقية بعد النشر على Blitz؛ اختبارات البيئة المحلية لا تستطيع إثبات قبول يوتيوب أو تيك توك للاتصال الصادر من الخادم.
